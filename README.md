## Featured project

**[CSV Triage](https://github.com/benjaminursu-hub/csv-triage)**: find inconsistent repair records before you analyse them.

- Checks CSV exports against explicit rules, including a profile for the Open Repair Data Standard
- On a real release of 305,649 repair records, it showed that two providers publish no fault descriptions at all, and that naive ID checks report thousands of false duplicates
- Python with no dependencies, a local dashboard, 62 tests and CI on Windows and Linux
